Connecting your agent

Archer serves an MCP server at tryarcher.dev/mcp. Any MCP client can read, validate and write your projects through it, signed in as you.

SHEET A-104

  1. 1

    Add the server

    One line in Claude Code. Codex, Cursor, Gemini CLI and VS Code take the same URL in their MCP settings.

    claude mcp add --transport http archer https://tryarcher.dev/mcp
  2. 2

    Sign in once

    Your browser opens and you sign in with GitHub. There are no API keys to paste or rotate.

  3. 3

    Ask for a drawing

    Point it at a repo and ask it to map the system, or paste the agent prompt and let it set everything up.

Requests for information

RFI-01

Do I need an account to try it?

No. The example sandboxes run in your browser and nothing is saved.

RFI-02

Which agents work?

Any MCP client: Claude Code, Codex, Cursor, Gemini CLI, VS Code and others.

RFI-03

Can I start from an existing codebase?

Yes. The agent prompt asks your agent to read the repo and draw what it finds.

RFI-04

Can I use my own components?

Yes. Define custom types with your own names and glyphs, in the canvas or through MCP.
