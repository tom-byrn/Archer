    MCP server

    One line connects your agent.

    Archer runs a hosted MCP server. Add it, sign in when your agent asks, and it can read, write and render your documents.

    claude mcp add --transport http archer https://tryarcher.dev/mcp

    Works with Claude Code, Codex, Cursor, Gemini CLI, VS Code and any other MCP client. Sign-in is OAuth, so there are no API keys to paste.

    Questions

    Short answers.

    Do I need an account to try it?
    No. Every worked example opens in a sandbox, and nothing you change there is saved.
    Which agents work?
    Any MCP client: Claude Code, Codex, Cursor, Gemini CLI, VS Code and others.
    Can I start from an existing codebase?
    Yes. The agent prompt asks your agent to map the repository into a new document.
    Can I use my own components?
    Yes. Define custom types with their own name, color and glyph.
