        MCP

        Connect your agent.

        Archer's MCP server is hosted at tryarcher.dev/mcp. Add it once, sign in with GitHub when your agent asks, and it can read, write and validate your diagrams.

        • Add the server. One command or a few lines of config in any MCP client.
        • Sign in once. Standard OAuth through GitHub. No API keys to paste or rotate.

        Questions

        Before you start.

        Do I need an account to try it?

        No. The example sandboxes run in your browser with the full editor. Nothing is saved, and leaving the page discards your edits.

        Which agents work?

        Any MCP client: Claude Code, Codex, Cursor, Gemini CLI, VS Code and others. They all talk to the same hosted server.

        Can I start from an existing codebase?

        Yes. The agent prompt asks your agent to read the repo and map it: components, planes, connections and the src paths that point back at the code.

        Can I use my own components?

        Yes. Create custom types with their own name, color and glyph, in the editor or through the MCP tools.
