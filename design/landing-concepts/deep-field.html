MCP server

Connect your agent to the same file.

Archer runs a hosted MCP server. Add it once, sign in with GitHub in the browser, and your agent can list your projects, read a document, validate a change and write it back.

claude mcp add --transport http archer https://tryarcher.dev/mcp

Field notes

Questions people ask.

Do I need an account to try it?
No. Every example opens in a sandbox: the full editor, kept in memory, gone when you leave.
Which agents work?
Any MCP client: Claude Code, Codex, Cursor, Gemini CLI, VS Code and the rest.
Can I start from an existing codebase?
Yes. The agent prompt has your agent map the repository and write the first document, with src paths back to the code.
Can I use my own components?
Yes. Save custom types with your own name, color and glyph, and use them anywhere in the workspace.
