the day after the meeting

  
A whiteboard is perfect for about an hour.

  
Then someone erases half of it, the photo lives in a chat thread, and nobody can say what is still true. Here is what each of those moments looks like in Archer.


  

    

      

        
who changed this?Every revision, with a real diff.

        
Every save is kept, whether a person or an agent made it. Diffs list what was added, removed or changed, and agent edits stay badged until you review them.

agents can't read whiteboards.They read Archer over MCP.

        
Your agent reads and writes the same document you draw: components, connections, and the schemas and notes inside them. Its writes go through the same validation as the canvas, so a broken document is rejected, not saved.

questions from the margins

  
Everything else you'd scribble in the corner.

  

    
can it draw our AWS stuff?
80+ component types
Agents, LLMs, RAG, MCP servers, AWS, GCP, Azure, Vercel, databases, queues and SaaS, each with its own glyph. Add custom types for anything missing.

    
frontend over here, backend over there
Planes and nesting
Lay components out on titled planes like frontend, backend or VPC. Any component can hold its own parts: double-click to open it, breadcrumbs lead back out.

    
where's the schema??
Data inside components
Attach a schema, API contract or notes as JSON, YAML or tables, validated as you type. Your agent gets all of it.

    
can the whole team edit it?
Teams and roles
Personal and team workspaces with owners, editors and viewers. Invite people by email.

    
do I need an account to try?
No
Open an example sandbox and change anything. Nothing is saved, and leaving the page discards your edits.

    
we already have a codebase
Start from your repo
Copy the agent prompt into your coding agent and it maps the repo into a new Archer project, then asks before it creates anything.

  







  
one command

  
Hand your agent the marker.

  
Archer's MCP server is hosted at tryarcher.dev/mcp. There is no API key to paste: your agent opens the browser and you sign in with GitHub.

  

    

      

        
        
        
        
        
      

      

        
claude mcp add --transport http archer https://tryarcher.dev/mcp

        
      

      
Then run /mcp, choose archer and sign in with GitHub.

      

        
Not sure where to start? The agent prompt installs the server, signs you in and offers to map your codebase.
