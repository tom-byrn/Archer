# @archer/mobile

Archer's companion app for iOS and Android (Expo, React Native): your
documents, their diagrams and components, code, history and share links, on
the same account and backend as the web app.

```sh
cp .env.example .env.local   # the web app's Convex URL and Clerk key
pnpm start                   # or: pnpm mobile, from the repository root
```

Setup, how it shares code with the web app, and checks: [docs/mobile.md](../../docs/mobile.md).
